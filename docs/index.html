convertkit

Agentic-first data format conversion service
Single Go binary · Zero external deps · Plain text API

Supported Formats

JSON
JavaScript Object Notation
YAML
YAML Ain't Markup Language
TOML
Tom's Obvious Minimal Language
CSV
Comma-Separated Values
XML
eXtensible Markup Language
Properties
Java key=value format
JSONL
JSON Lines
Env
Environment variables

Quick Start

# Build and run make build ./convertkit # Convert JSON to YAML curl -X POST -H 'Authorization: Bearer TOKEN' \ -d '{"name":"test","value":42}' \ 'http://localhost:7700/convert?from=json&to=yaml' # Response (plain text) name: test value: 42

Key Features

  • 8 format support — JSON, YAML, TOML, CSV, XML, Properties, JSONL, Env
  • Custom parsers — YAML, TOML, and XML parsers written from scratch (zero external deps)
  • OTP auth — Email → OTP → bearer token flow
  • Multi-tenant — Workspaces, audit logs, conversion history
  • MCP endpoint — JSON-RPC 2.0 at /mcp for chat client integrations
  • Self-documenting — GET /help returns a one-page operating manual
  • Plain text by default — JSON available via Accept header
  • Instructive errors — Every 4xx includes a hint for self-correction
  • Single binary — CGO_ENABLED=0, deploys as one file
